>

One micro-confession in exactly two parts — a `To:` line and the one unsent line, written exactly as it was typed. Built for make.fun's "Unsent: The Micro-Confession Sprint" bounty.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`.
